# 🛍️ General Store

### Discover. Explore. Connect.

**General Store** is a multi-page e-commerce website designed to make product discovery simple and convenient. It brings different product categories together in one place, allowing customers to explore products and contact the business directly for enquiries.

The project focuses on a clean browsing experience, organised product presentation and easy customer communication.

---

## 🌐 Project Overview

Finding different products online should be simple.

General Store provides a central platform where visitors can explore a variety of products, navigate through different categories and make enquiries without complicated processes.

Whether someone is looking for a laptop, smartphone, bicycle, vehicle or fashion accessory, the website provides an organised way to discover available products.

## 🚀 Run the Project Locally

Want to explore the project or run it on your computer?

Follow these steps:

**1. Clone the repository**

```bash
git clone https://github.com/dismaswetaba/e_comerce_website.git
```

**2. Enter the project directory**

```bash
cd e_comerce_website
```

**3. Open the website**

Open `index.html` in your browser.

You can also open the project in Visual Studio Code and use the Live Server extension.
